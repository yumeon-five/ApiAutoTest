# MD 输出模板（API 接口测试用例 Markdown 模板）

本文档只描述最终用例文件的 Markdown 结构。生成策略、覆盖范围、断言写法见 `testcase-spec.md`；Excel 列格式见 `apicase-template-excel.md`。

## 文件命名

`<接口名>_测试用例.md`，例如 `登录接口_测试用例.md`。

## 文件模板

每个接口一个文件。文件由 `frontmatter` + 若干条 `## <接口名> - <场景名称>` 详细用例段落组成。

```markdown
---
interface_key: <接口唯一标识，与 cases.json 的分组键一致>
interface_name: <接口中文名>
---

## <接口名> - <场景名称>

### 用例信息

| 字段 | 内容 |
| ---- | ---- |
| 用例编号 | <32 位 hex，取自 接口_index.json> |
| 测试标题 | <接口名>-<场景名称> |
| 前置条件 | <前置条件，无则填「无」> |
| 优先级 | <P0 / P1 / P2 / P3> |

### 请求信息

| 项目 | 内容 |
| ---- | ---- |
| 请求URL | {{ URL }}<请求路径> |
| 请求方法 | <GET / POST / PUT / DELETE> |

### 请求头

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| <请求头名称> | <请求头值> | <请求头说明> |

### URL参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| <参数名> | <测试数据占位符> | <参数说明> |

### 请求体参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| <参数名> | <测试数据占位符> | <参数说明> |

### 预期结果

- 响应状态码：<HTTP状态码>
- 响应格式：<JSON / XML / ...>
- <业务断言1>
- <业务断言2>
```

## 填写规则

- 每个用例文件**只**包含 `frontmatter` 和 `## 详细用例` 两类内容，**禁止生成「用例总览」章节**。
- `关联接口 key` 写在 frontmatter 的 `interface_key` 字段，**不要**单独写表格或章节。
- 多条用例时，每条用例追加一个 `## <接口名> - <场景名称>` 详细段落。
- 无请求头 / 无 URL 参数 / 无请求体时，保留对应表格标题，预留一个空行，**不要删除整节**。
- `用例编号` 必须取自 `接口_index.json::interfaces[interface_key].caseIds`，与 Excel 完全一致，禁止另起编号。
- 动态测试数据统一使用 Jinja2 风格占位符：`{{ 变量名 }}`，例如 `{{ 正确账号 }}`、`{{ 有效Token }}`。
- 优先级统一使用 `P0`/`P1`/`P2`/`P3`。

## 完整示例（登录接口）

```markdown
---
interface_key: loginUser
interface_name: 登录接口
---

## 登录接口 - 正确账号密码登录

### 用例信息

| 字段 | 内容 |
| ---- | ---- |
| 用例编号 | a1b2c3d4e5f647899abcdef012345678 |
| 测试标题 | 登录接口-正确账号密码登录 |
| 前置条件 | 数据库存在账号 {{ 正确账号 }} / 密码 {{ 正确密码 }} |
| 优先级 | P0 |

### 请求信息

| 项目 | 内容 |
| ---- | ---- |
| 请求URL | {{ URL }}/api/login |
| 请求方法 | POST |

### 请求头

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| Content-Type | application/json | JSON 请求体 |

### URL参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |

### 请求体参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| username | {{ 正确账号 }} | 登录用户名 |
| password | {{ 正确密码 }} | 登录密码 |

### 预期结果

- 响应状态码：200
- 响应格式：JSON
- code 等于 0
- msg 包含"成功"
- data.token 存在且非空（JSONPath: `$.data.token`）
```
