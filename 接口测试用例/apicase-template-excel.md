| 列名         | 说明                                                    | 对应 Markdown 内容          | 示例                                                         |
| :----------- | :------------------------------------------------------ | :-------------------------- | :----------------------------------------------------------- |
| 接口Key      | 关联接口的唯一标识                                      | frontmatter `interface_key` | `loginUser`                                                  |
| 用例编号     | 唯一标识                                                | 用例信息表 → 用例编号       | `TC_LOGIN_001`                                               |
| 测试标题     | 接口名-场景名称                                         | 用例信息表 → 测试标题       | `登录接口-正确账号密码登录`                                  |
| 前置条件     | 执行前需满足的条件                                      | 用例信息表 → 前置条件       | `数据库中存在账号 test01 / 密码 123456`                      |
| 优先级       | High / Medium / Low                                     | 用例信息表 → 优先级         | `High`                                                       |
| 请求URL      | 完整URL（可使用占位符）                                 | 请求信息表 → 请求URL        | `{{base_url}}/api/v1/login`                                  |
| 请求方法     | GET / POST / PUT / DELETE 等                            | 请求信息表 → 请求方法       | `POST`                                                       |
| 请求头       | 格式：`参数名: 值`，多个用换行分隔                      | 请求头表格                  | `Content-Type: application/json` `Authorization: {{有效Token}}` |
| URL参数      | 格式：`参数名: 值`，多个换行                            | URL参数表格                 | `userId: {{用户ID}}` `page: 1`                               |
| 请求体参数   | 格式：`参数名: 值` 或 JSON 字符串                       | 请求体参数表格              | `{"username":"{{正确账号}}","password":"{{正确密码}}"}`      |
| **预期结果** | 包含： - 响应状态码 - 响应格式 - 业务断言（多条可换行） | 预期结果章节                | `响应状态码：200` `响应格式：JSON` `code 字段为 0` `message 为 "success"` `data.token 不为空` |
