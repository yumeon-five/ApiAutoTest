## 查询可用供应商接口 - 携带有效Token分页查询可用供应商

### 用例信息

| 字段 | 内容 |
| ---- | ---- |
| 用例编号 | c7d6f6e1482345eb9db3761ec962e24d |
| 测试标题 | 查询供应商-携带有效Token分页查询可用供应商 |
| 前置条件 | 已成功登录并提取 {{ 有效Token }}、{{ 操作员ID }}；当前用户下存在至少一个可用供应商 |
| 优先级 | P0 |

### 请求信息

| 项目 | 内容 |
| ---- | ---- |
| 请求URL | {{ URL }}/supplier/ |
| 请求方法 | GET |

### 请求头

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| Content-Type | application/json | JSON 请求头 |
| Accept | application/json | 期望 JSON 响应 |
| token | {{ 有效Token }} | GreaterWMS 认证凭据（登录返回的 openid） |
| operator | {{ 操作员ID }} | 登录返回的 user_id |

### URL参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| page | {{ 当前页码 }} | 页码，非必填 |
| max_page | {{ 分页大小 }} | 每页数量，非必填 |
| format | json | 响应格式 |

### 请求体参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |

### 预期结果

- 响应状态码：200
- 响应格式：JSON
- count 大于 0（JSONPath: `$.count`）
- results 为非空数组
- results[0].supplier_name 存在且非空（JSONPath: `$.results[0].supplier_name`）
- results[0].id 为正整数
- 提取 supplier_name=`$.results[0].supplier_name` 供后续创建 ASN 明细使用
