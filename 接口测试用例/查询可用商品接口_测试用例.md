## 查询可用商品接口 - 携带有效Token分页查询可用商品

### 用例信息

| 字段 | 内容 |
| ---- | ---- |
| 用例编号 | 06bbec909a6b46b198aaab0ef11f2262 |
| 测试标题 | 查询商品-携带有效Token分页查询可用商品 |
| 前置条件 | 已成功登录并提取 {{ 有效Token }}、{{ 操作员ID }}；当前用户下存在至少一个可用商品 |
| 优先级 | P0 |

### 请求信息

| 项目 | 内容 |
| ---- | ---- |
| 请求URL | {{ URL }}/goods/ |
| 请求方法 | GET |

### 请求头

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| Content-Type | application/json | JSON 请求头 |
| Accept | application/json | 期望 JSON 响应 |
| token | {{ 有效Token }} | GreaterWMS 认证凭据（登录返回的 openid） |
| operator | {{ 操作员ID }} | 登录返回的 user_id |

### URL参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| page | {{ 当前页码 }} | 页码，非必填 |
| max_page | {{ 分页大小 }} | 每页数量，非必填 |
| format | json | 响应格式 |

### 请求体参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |

### 预期结果

- 响应状态码：200
- 响应格式：JSON
- count 大于 0
- results 为非空数组
- results[0].goods_code 存在且非空（JSONPath: `$.results[0].goods_code`）
- results[0].goods_desc 存在且非空
- 提取 goods_code=`$.results[0].goods_code` 供后续 ASN 明细与库存校验使用
