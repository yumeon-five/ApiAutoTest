## 查询商品总库存接口 - 创建ASN明细前获取库存基线

### 用例信息

| 字段 | 内容 |
| ---- | ---- |
| 用例编号 | 89aee04a53e242599087f162ca35a078 |
| 测试标题 | 查询商品总库存-创建ASN明细前获取库存基线 |
| 前置条件 | 已成功登录并提取 {{ 有效Token }}、{{ 操作员ID }}；已通过商品接口提取 {{ 商品编码 }} |
| 优先级 | P0 |

### 请求信息

| 项目 | 内容 |
| ---- | ---- |
| 请求URL | {{ URL }}/stock/list/ |
| 请求方法 | GET |

### 请求头

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| Content-Type | application/json | JSON 请求头 |
| Accept | application/json | 期望 JSON 响应 |
| token | {{ 有效Token }} | GreaterWMS 认证凭据（登录返回的 openid） |
| operator | {{ 操作员ID }} | 登录返回的 user_id |

### URL参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| goods_code | {{ 商品编码 }} | 商品编码，必填 |
| page | {{ 当前页码 }} | 页码，非必填 |
| max_page | {{ 分页大小 }} | 每页数量，非必填 |
| format | json | 响应格式 |

### 请求体参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |

### 预期结果

- 响应状态码：200
- 响应格式：JSON
- results 为数组
- 当 count>0 时 results[0].goods_code 等于 {{ 商品编码 }}
- 保存 goods_qty、onhand_stock、can_order_stock、asn_stock、pre_load_stock、pre_sort_stock、sorted_stock 等字段作为后续增量断言基线
- 当 count=0 时对应基线按 0 处理
