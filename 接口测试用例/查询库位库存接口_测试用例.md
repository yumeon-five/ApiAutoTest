### 用例信息

| 字段 | 内容 |
| ---- | ---- |
| 用例编号 | 9c02fa88f1be47c7a5784e4340ba10d8 |
| 测试标题 | 查询库位库存-上架完成后核对库位库存增量 |
| 前置条件 | 已完成 ASN 全量上架（明细状态 5）；已提取 {{ 商品编码 }}、{{ 库位名称 }}、{{ 有效Token }}、{{ 操作员ID }}；已保存上架前库位库存基线 |
| 优先级 | P0 |

### 预期结果

- 响应状态码：200
- 响应格式：JSON
- count 大于等于 1
- results 中存在 bin_name 等于 {{ 库位名称 }} 且 goods_code 等于 {{ 商品编码 }} 的记录
- 该库位对应商品数量合计比基线增加 {{ 上架数量 }}
- results[0].bin_property 等于 "Normal"
- 对应库位由 empty_label=true 变为非空
- 接口返回值与数据库 stockbin 表实际记录一致
