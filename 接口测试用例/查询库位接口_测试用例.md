## 查询库位接口 - 筛选Normal类型且未占用的空库位

### 用例信息

| 字段 | 内容 |
| ---- | ---- |
| 用例编号 | 624ad74a4cc64c06b2852ad72ef92cc9 |
| 测试标题 | 查询库位-筛选Normal类型且未占用的空库位 |
| 前置条件 | 已成功登录并提取 {{ 有效Token }}、{{ 操作员ID }}；系统中存在至少一个 bin_property=Normal 且 empty_label=true 的空库位 |
| 优先级 | P0 |

### 请求信息

| 项目 | 内容 |
| ---- | ---- |
| 请求URL | {{ URL }}/binset/ |
| 请求方法 | GET |

### 请求头

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| Content-Type | application/json | JSON 请求头 |
| Accept | application/json | 期望 JSON 响应 |
| token | {{ 有效Token }} | GreaterWMS 认证凭据（登录返回的 openid） |
| operator | {{ 操作员ID }} | 登录返回的 user_id |

### URL参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| bin_property | Normal | 库位属性，必填 |
| empty_label | true | 是否为空库位，必填 |
| page | {{ 当前页码 }} | 页码，非必填 |
| max_page | {{ 分页大小 }} | 每页数量，非必填 |
| format | json | 响应格式 |

### 请求体参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |

### 预期结果

- 响应状态码：200
- 响应格式：JSON
- count 大于 0
- results 为非空数组
- results[0].bin_property 等于 "Normal"
- results[0].empty_label 为 true
- results[0].bin_name 存在且非空
- 提取 bin_name=`$.results[0].bin_name` 供后续上架用例使用
