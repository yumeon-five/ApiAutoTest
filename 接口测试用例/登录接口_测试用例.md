## 登录接口 - 正确账号密码登录成功

### 用例信息

| 字段 | 内容 |
| ---- | ---- |
| 用例编号 | 484b2ebd3ca2451ea685bd460a875ac3 |
| 测试标题 | 登录接口-正确账号密码登录成功 |
| 前置条件 | 数据库存在有效账号 {{ 正确账号 }} / 密码 {{ 正确密码 }} |
| 优先级 | P0 |

### 请求信息

| 项目 | 内容 |
| ---- | ---- |
| 请求URL | {{ URL }}/login/ |
| 请求方法 | POST |

### 请求头

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| Content-Type | application/json | JSON 请求体 |
| Accept | application/json | 期望 JSON 响应 |

### URL参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |

### 请求体参数

| 参数名 | 值 | 说明 |
| :----- | :--- | :--- |
| name | {{ 正确账号 }} | 登录用户名（必填） |
| password | {{ 正确密码 }} | 登录密码（必填） |

### 预期结果

- 响应状态码：200
- 响应格式：JSON
- code 等于 "200"
- msg 包含 "Success Create"
- data.openid 存在且非空（JSONPath: `$.data.openid`）
- data.user_id 为正整数（JSONPath: `$.data.user_id`）
- 提取 token=`$.data.openid`、operator=`$.data.user_id` 供后续业务接口使用

| 参数名 | 值 | 说明 |
